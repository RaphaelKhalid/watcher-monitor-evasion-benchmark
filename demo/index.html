01 / THE FINDING

Raw-text matching is not shell semantics.

NARROW CLAIM

Watcher’s public design describes regex rules where an allow match skips further grading. In the shipped policy, some allow patterns are anchored at the start of the raw Bash string.

A shell command can therefore begin with an apparently safe operation and continue with a sensitive mutation. Our offline replica found two reproducible families:

  • echo → crontabthe environment-info rule sees echo before the pipe
  • git status → config mutationthe read-only Git rule sees git status before &&

04 / METHOD

Reproducible by design.

  1. 01

    Load the installed 736-line policy in WSL, in place.

  2. 02

    Sort 63 command rules by numeric priority and apply regex matching to Bash strings.

  3. 03

    Compare a direct dangerous command with benign and mechanical rewrites.

  4. 04

    Save every decision, matched rule, and priority to raw JSON.

05 / LIMITS

What this does not prove.

This is a router finding, not a full Watcher bypass. A triage route is not an approval. The next validation is to replay inert synthetic trajectories through the documented API and compare the full monitor outcome.
